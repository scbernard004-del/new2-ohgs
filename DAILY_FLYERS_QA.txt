- Both supplied OHGS artworks retained in full. Branding, contact details and actual equipment are preserved.

- Chrome responsive preview checked at 320 and 390 CSS-pixel frame widths, 768 tablet width and 1100 desktop frame width, plus the full desktop browser.

PACKAGE AND PERFORMANCE
- Local-reference, title, translation, SEO, canonical, sitemap, ordering, accessibility-attribute and image checks passed for all public pages.
- Responsive images use 480 / 768 / original-width WebP sources with JPEG fallback. The smallest new plant source is 64,164 bytes; the Friday source is 44,074 bytes.
- The inactive Friday template does not request its image for the ordinary daily feature.
- Existing showroom playback was observed running automatically, muted, at 8.3 seconds of a 40.7-second clip, without a media error.
- All earlier media are preserved unchanged in the package.
- npm run qa, npm run build, JavaScript syntax checks and ZIP integrity verification are the final package checks.

LIMITS
Responsive checks used Chrome, not every physical phone or browser. The calendar depends on an accurately set device clock. WhatsApp delivery, real customer enquiries and the live Vercel domain were not tested as part of the local preview. Vercel returned a team-access 403, so publishing requires team authorization or the user's normal GitHub/Vercel upload workflow. This package alone does not update the live domain.
